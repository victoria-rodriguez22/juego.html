# Juego: Adivina el número

Juego web interactivo en JavaScript.
Reglas:
‑ Elige un número aleatorio entre 1 y 100
‑ Cuentas con máximo 10 intentos
‑ Te indica si tu número es muy alto o muy bajo
‑ Muestra todos los números que ya probaste
‑ Permite volver a jugar cuando termina la partida

## Tecnologías
‑ HTML
‑ CSS
‑ JavaScript
