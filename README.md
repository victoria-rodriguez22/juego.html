# Juego: Adivina el Número
*Victoria Alexandra Casillas Rodríguez*

## Descripción
Se genera un número aleatorio entre 1 y 100 y el jugador cuenta con 10 intentos para adivinarlo. Después de cada intento se le indica si acertó o, en caso contrario, si el número secreto es mayor o menor al ingresado; además se muestran los valores que ya ha probado. El juego finaliza cuando el jugador acierta o cuando se agotan los intentos, y al terminar se le ofrece la opción de volver a jugar.

## Funcionalidades
- Número aleatorio del 1 al 100
- 10 intentos como máximo
- Indica si el número es mayor o menor
- Muestra los números ya probados
- Opción de repetir el juego
- Validación de entradas correctas
